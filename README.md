## GitHub Pages 공개하기

1. 저장소 상단 **Settings** → 왼쪽 **Pages**를 엽니다.
2. **Build and deployment**의 Source에서 **Deploy from a branch**를 고릅니다.
3. Branch를 **main**, Folder를 **/(root)**로 지정하고 **Save**합니다.
4. GitHub가 게시 완료를 알리면 `https://kmc080406.github.io/-/bbangdi-wallet/` 에서 접속할 수 있습니다.

> 사이트와 GitHub 저장소는 공개됩니다. 편지나 방송 관련 문구를 공유하기 전에 확인해 주세요.
